# Demonstration photos

To replace an image, overwrite the JPEG with the same name, or update the corresponding `src` path in the Projects & Demonstrations section of `index.html`:

- `marc-raibert.jpg` — Marc Raibert’s lab visit
- `mars-2026.jpg` — MARS Conference 2026

The cards use a 16:9 frame. Update the image’s `alt` text in `index.html` to describe any replacement photo.
